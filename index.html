Book Library Application / BookFlix

Problem: A personal comic and manga collection had no organized way to browse, edit, or manage online, and existing entries could not be reliably updated or deleted.

Solution: A book library manager with full CRUD features (add, edit, delete), automatic category sections (Manga, Marvel, DC), a favorites system, a random "Suggested for you" carousel with a 3D hover effect, and a direct Amazon search link on every book card.

Stack: React, TypeScript, Vite, Tailwind CSS, Axios, mockapi.io.

Challenge: Tracking down a silent edit/delete failure caused by improperly indexed API records, then fine-tuning a smooth 3D hover animation for the suggestions carousel without layout jitter or clipping.

Result: a categorized, interactive library with favorites, smart suggestions, and a polished, bug-free browsing experience.

React • TypeScript • Tailwind CSS • Vite • Axios
