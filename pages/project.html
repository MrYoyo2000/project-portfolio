PROJECT IN JAVASCRIPT, PYTHON, HTML

In 2022 I created a Discord bot in JavaScript to automate and improve server interactions. The bot handled custom commands managed roles sent automatic messages and supported basic moderation features.

It also responded to user actions and provided real-time information when needed. This project helped me understand event handling, API integration, and how to structure a functional bot using Discord.js.

In early 2025 I developed a Wallet Tracker in Python designed to monitor cryptocurrency addresses in real time. The tool tracks selected wallets shows incoming and outgoing transactions and provides live updates as transfers occur.

It allows users to follow balances detect movements instantly and analyze activity across multiple addresses. Through this project I strengthened my understanding of blockchain data API integration and real time monitoring while building a practical tool for on-chain tracking.

I started building my Bitcoin Blockchain Tracker three months ago. The tool is dedicated entirely to the Bitcoin network and scans the blockchain in real time displaying every transaction as it happens. It automatically separates normal transfers from large “whale 🐋” movements allowing me to clearly identify major transactions on the terminal.

I analyze these movements in parallel on TradingView to understand how large transfers from "whales 🐋" companies, or institutional wallets impact market price action. By comparing on-chain activity with live charts the tracker helps reveal how heavy buying, selling, or fund movements influence market behavior.

The project is still in development, but the long-term goal is to turn it into a professional tool that provides complete visibility into Bitcoins on-chain activity : who is moving large amounts ? , when ?, why? and how it affects the market. In the future I aim to sell this software to banks, institutions, or individuals who need precise, real time monitoring of Bitcoin transactions and "whales 🐋" activity.
